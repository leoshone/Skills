# Skills

可复用的 AI agent skills（通用方法沉淀），跨项目共享。

| Skill | 用途 |
|---|---|
| [browser-extension-e2e](browser-extension-e2e/) | Windows Chromium 系浏览器（Cent/Turbo 等保留 MV2 的国产内核）扩展安装 + CDP 自动化 E2E 测试 |
| [avd-install-apk](avd-install-apk/) | 在 Android 模拟器（AVD）安装第三方 APK/APKS/XAPK：下载源选择、split 包安装、踩坑速查 |

## 使用

把对应 skill 目录复制到项目级。
